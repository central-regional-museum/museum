# Central Regional High School Museum

Public interactive prototype with seven explicitly labeled demo exhibits and original vector explorer characters. No student records, credentials, real artifact photographs, or private document links are included. Live collaboration trading is not implemented.

Build: `node tools/build.mjs --import collection.json`

Check: `node tools/check.mjs`

GitHub Pages publishes the generated dist directory through Actions. Replace demonstration entries with teacher-reviewed artifact stories before classroom use. The empty passport-template setting awaits a teacher-approved public template. Only repository collaborators can publish updates.
