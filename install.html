Open School Museum in one tap

Add it once, then use its icon to open the live site. Your progress or sign-in stays in the browser/device where you use it.

Open School Museum

iPhone or iPad

Best branded icon: open School Museum in Safari, tap Share → Add to Home Screen → Add.

Or download the Apple Shortcut below, open it in Shortcuts and tap Add Shortcut. It contains only the website address. It does not contain a teacher code or student data.

Download iPhone / iPad shortcut

To put that shortcut on your Home Screen: open its details in Shortcuts → Add to Home Screen. Tap its icon to choose the museum image below if you want a custom icon.

Android · Chrome

Open School Museum in Chrome
  1. Tap Chrome’s three-dot menu.
  2. Choose Add to Home screen, then Install or Create shortcut.
  3. Tap the new branded icon whenever you need School Museum.

Some school-managed devices restrict installation. A bookmark still opens the same site.

Chrome · computer

Open School Museum in Chrome. Use the install icon in the address bar, or the menu → Cast, save and share → Install page as app. Menu names can vary by Chrome version.
